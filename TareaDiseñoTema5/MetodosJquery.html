📚 Cheatsheet jQuery

Métodos esenciales para desarrollo web

$("selector").metodo();

🎯 SELECCIÓN

$("p")
Todos los elementos <p>
$("#id")
Elemento con ID específico
$(".clase")
Elementos con clase específica
$("div.clase")
Divs con clase específica
$("ul li:first")
Primer elemento li dentro de ul
$(this)
Elemento actual en un evento

🔧 MANIPULACIÓN

.text("nuevo texto")
Cambia el texto del elemento
.html("<b>texto</b>")
Cambia el HTML interno
.val()
Obtiene el valor de inputs
.append("<div>nuevo</div>")
Añade contenido al final
.prepend("<div>nuevo</div>")
Añade contenido al principio
.remove()
Elimina el elemento

🏷️ CLASES Y ATRIBUTOS

.addClass("clase")
Añade una clase CSS
.removeClass("clase")
Elimina una clase CSS
.toggleClass("clase")
Alterna una clase CSS
.css("color", "red")
Cambia estilo CSS
.attr("href", "nuevo")
Cambia atributo HTML
.prop("disabled", true)
Cambia propiedad (disabled, checked...)

🎮 EVENTOS

.click(function() { ... })
Al hacer clic
.dblclick(function() { ... })
Al hacer doble clic
.hover(function() { ... })
Al pasar el ratón
.keypress(function() { ... })
Al pulsar tecla
.change(function() { ... })
Al cambiar valor (input, select)
$(document).ready(function() { ... })
Cuando el DOM está listo

✨ EFECTOS

.hide() / .show()
Oculta/Muestra elemento
.fadeOut() / .fadeIn()
Desvanece/Aparece elemento
.slideUp() / .slideDown()
Desliza hacia arriba/abajo
.toggle()
Alterna entre mostrar/ocultar
.animate({left: '250px'})
Animación personalizada
.delay(1000)
Retrasa la siguiente acción (ms)

🔍 TRAVERSING

.parent()
Padre directo
.children()
Hijos directos
.find("selector")
Busca dentro del elemento
.next() / .prev()
Siguiente/Anterior hermano
.siblings()
Todos los hermanos
.first() / .last()
Primer/Último elemento del conjunto

📌 Tip: jQuery usa la sintaxis $("selector").metodo()
