⏱️ TRANSICIONES

transition: all 0.3s ease;
Transición básica (propiedad, tiempo, ritmo)
transition-property: background-color, transform;
Especifica propiedades a animar
transition-duration: 2s;
Duración de la transición
transition-timing-function: ease-in-out;
Ritmo de la animación
transition-delay: 1s;
Retraso antes de comenzar

Valores timing-function:

ease
Inicio/fin lento, medio rápido (default)
linear
Velocidad constante
ease-in
Inicio lento
ease-out
Final lento
ease-in-out
Inicio y final lentos

🎬 @KEYFRAMES (Animaciones)

@keyframes nombre {
  0% { /* inicio */ }
  100% { /* fin */ }
}
Definición básica de animación
animation: nombre 2s ease infinite;
Aplicar animación a elemento

Propiedades de animation:

animation-name
Nombre de la animación
animation-duration
Duración (ej: 3s)
animation-timing-function
Ritmo (ease, linear...)
animation-delay
Retraso inicial
animation-iteration-count
Repeticiones (infinite)
animation-direction
Dirección (normal, reverse, alternate)
animation-play-state
Estado (running, paused)

💡 EJEMPLOS PRÁCTICOS

1. Botón con hover:

.boton {
  transition: all 0.3s ease;
}
.boton:hover {
  transform: scale(1.1);
  background: #667eea;
}

2. Animación de carga:

@keyframes spin {
  0% { transform: rotate(0deg); }
  100% { transform: rotate(360deg); }
}
.spinner {
  animation: spin 1s linear infinite;
}

3. Movimiento suave:

@keyframes mover {
  0%, 100% { transform: translateX(0); }
  50% { transform: translateX(50px); }
}
.elemento {
  animation: mover 2s ease-in-out infinite;
}

4. Fade in/out:

@keyframes aparecer {
  0% { opacity: 0; }
  100% { opacity: 1; }
}
.nuevo {
  animation: aparecer 0.5s ease-out;
}

⚡ CONTROL CON JAVASCRIPT

// Pausar animación
elemento.style.animationPlayState = "paused";
// Reanudar animación
elemento.style.animationPlayState = "running";
// Cambiar animación dinámicamente
elemento.style.animation = "nuevaAnimacion 2s ease";
// jQuery para controlar animaciones
$("#elemento").css("animation-play-state", "paused");

Ejemplo del PDF (péndulo):

document.getElementById("parar").addEventListener("click", function() {
  document.getElementById("pendulo").style.animationPlayState = "paused";
});
