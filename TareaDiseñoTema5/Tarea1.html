Ejercicio 2-A: Menú con transiciones

Menú con efecto "cortina" al pasar el ratón

Requisito del ejercicio: "al pasar el ratón sobre una opción del menú, aparezca una cortina de color desplazándose de arriba hacia abajo"

✅ CUMPLIDO - Implementación:

  • Se utiliza un pseudo-elemento ::before como cortina
  • Posición inicial: top: -100% (fuera de vista, arriba)
  • Posición al hover: top: 0 (baja hasta cubrir el botón)
  • Transición: transition: top 0.3s ease para movimiento suave
  • Color de cortina: background-color: #2c3e50 (azul oscuro)

Ejercicio 3: Página Animaciones

Contiene tres animaciones diferentes como solicita la tarea

1. Slider con CSS @keyframes

Slider automático que cambia imágenes

✅ CUMPLIDO - Slider con @keyframes:

  • Requisitos:
    • "Realiza un slider a través de una animación con CSS (@keyframe)"
    • "La animación tiene que durar 10 segundos"
    • "Repitiéndose de forma ininterrumpida"
    • "Tiempo entre imagen e imagen debe durar el mismo tiempo"
  • Implementación: Animación @keyframes slide de 10 segundos
  • Duración: animation: slide 10s infinite
  • Tiempo por imagen: 2.5 segundos visibles + 0.5s transición = 3s total por imagen
  • 4 imágenes × 2.5s = 10 segundos totales (cumple requisito)
  • Repetición: infinite (ininterrumpida)

2. Barra de progreso con Canvas

Barra que muestra el número de likes que recibe la página

Tu navegador no soporta el elemento canvas.
0 / 200 likes

✅ CUMPLIDO - Barra de progreso con Canvas:

  • Requisitos:
    • "Dibuja, con canvas, una barra de progreso"
    • "Mostrará el número de likes que recibe la página"
    • "Irá de 0 a 200"
    • "Tendrá un botón que cada vez que se pulse aumentará la barra de progreso"
  • Implementación: Uso de Canvas API para dibujar barra
  • Rango: 0 a 200 likes exactamente
  • Botón "Dar Like": Incrementa en 10 likes cada click
  • Botón "Reiniciar": Vuelve a 0 likes
  • Animación: Barra se llena suavemente con requestAnimationFrame
  • Visualización: Muestra número actual / 200

3. Animación con SVG: Imágenes persiguiéndose

Dos figuras que se siguen mutuamente a través de una trayectoria

✅ CUMPLIDO - Animación con SVG:

  • Requisito: "Poner dos imágenes persiguiéndose a través de una trayectoria"
  • Implementación: Dos elementos <circle> SVG
  • Trayectoria: Circular definida por elemento <circle id="path">
  • Animación: <animateMotion> siguiendo la trayectoria
  • Persecución: Velocidades diferentes (6s vs 4s) para efecto de persecución
  • Controles: Botones para iniciar, detener e invertir dirección
  • Efectos adicionales: Animación de pulso y sombras para mejor visibilidad
